# 거리 보정 및 마켓 아이템 정리

## 거리 보정

거리는 플레이어의 가장 큰 수익원이 되는 것이 좋습니다.

| 거리 | 가격 배율 |
|---|---:|
| 같은 도시 | 100% |
| 인접 도시 | 110% |
| 2지역 | 125% |
| 3지역 | 145% |
| 4지역 | 170% |
| 대륙 반대편 | 200~230% |

## 추천 변동 폭

무역 게임에서 너무 큰 변동은 "운 게임"처럼 느껴지고, 너무 작은 변동은 거래할 이유가 없어집니다.

그래서 다음 정도를 추천합니다.

| 요소 | 권장 범위 |
|---|---:|
| 거리 | +0~130% |
| 계절 | -30% ~ +60% |
| 도시 특산품(생산지) | -20% |
| 도시 특산품(소비지) | +20% |

## 참고

- 위 마켓 표는 `tradeItems`와 `localSpecialtyItems`만 정리했습니다.
- `draftAnimalItems`와 `wagonItems`는 TradeItemSO가 아니므로 제외했습니다.
- SO와 마켓 파일은 읽기만 했으며 원본 프로젝트 파일은 수정하지 않았습니다.
