# 향후 작업 계획

## 1. 카라반 선택 UI와 선택 상태 연결

상태: 미착수

- 카라반 선택 UI에서 `selectedCaravanId`를 갱신한다.
- 카라반 버튼을 누르면 해당 카라반의 관련 UI를 표시할 수 있도록 선택 ID를 반환한다.
- 버튼 클릭 시 `selectedCaravanId`를 포함한 이벤트를 발행한다.
- UI가 자체적으로 별도 선택 상태를 만들지 않고, Framework 및 SaveData가 사용하는 선택 기준과 일치하도록 연결한다.

## 2. 무역 실패 정산창 복구

상태: 원인 알림 연결 완료, 실패 정산창 복구는 미완료

- 무역 실패 시 정산창이 표시되지 않는 문제를 수정한다.
- 실패 결과와 정산 대기 상태는 Framework와 SaveData를 기준으로 조회한다.
- UI가 임시 상태만 보고 정산 여부를 판단하지 않도록 저장·복원 흐름까지 함께 검증한다.

## 3. 마을 꾸미기 UI

상태: UI 골격 완료, 실제 편집 저장·종료 흐름은 후속 작업

- 기존 건물 생성 버튼 영역에 편집모드 진입 버튼을 둔다.
- 목록을 `건물`과 `환경` 카테고리로 나눈다.
- 각 카테고리는 누르면 하위 항목이 펼쳐지고 다시 누르면 접히는 드롭다운 형태로 표시한다.
- 현재 프리팹과 연결 구조는 `Village_Edit_Mode_And_Accordion_UI_Guide.md`를 참조한다.
- 편집모드 진입, 팝업 자동 닫기, 건물/환경 드롭다운과 Inspector 확장 지점은 구현되어 있다.
- 편집 저장 버튼은 독립 프리팹만 준비되어 있으며 실제 저장 정책과 화면 배치는 아직 연결하지 않는다.

## 4. 마차·동물 인벤토리 구현

상태: 미착수

- 마차 인벤토리와 동물 인벤토리를 구현한다.
- 인벤토리 구현에 맞춰 Caravan Set이 마차·동물 데이터를 참조하는 방식을 변경한다.
- 편성 초안, 저장된 카라반 구성, 실제 인벤토리의 책임 경계를 유지한다.

## 5. 이름 수정

상태: 후순위 보류

- 플레이어 이름 수정 기능을 추가한다.
- 카라반 이름 수정 기능을 추가한다.
- 이름 수정 작업은 위 기능들이 안정된 이후로 미룬다.
